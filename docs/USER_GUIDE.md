# VibeGrid — User Guide ⚡

Welcome to VibeGrid! VibeGrid is a free, open-source, GPU-accelerated multi-pane terminal workspace designed for orchestrating AI coding agents and terminal tasks.

---

## 1. Installation

### macOS
1. Download `VibeGrid_x64.dmg` or `VibeGrid_aarch64.dmg` (Apple Silicon M1/M2/M3/M4).
2. Drag VibeGrid into your `Applications` folder.
3. Launch VibeGrid from Spotlight or Launchpad.

### Windows
1. Download `VibeGrid-Setup.msi` or `.exe`.
2. Double-click the installer and follow the prompt.

---

## 2. Core Keyboard Shortcuts

VibeGrid is designed to be **keyboard-first**. You can customize all keybindings in **Settings (`Cmd/Ctrl+,`)**.

| Action | macOS Shortcut | Windows/Linux Shortcut |
|---|---|---|
| **Split Horizontally (Side-by-Side)** | `Cmd + D` | `Ctrl + D` |
| **Split Vertically (Stacked)** | `Cmd + Shift + D` | `Ctrl + Shift + D` |
| **Close Focused Pane** | `Cmd + W` | `Ctrl + W` |
| **Maximize / Restore Pane** | `Cmd + Shift + Enter` | `Ctrl + Shift + Enter` |
| **Open Command Palette** | `Cmd + Shift + P` | `Ctrl + Shift + P` |
| **Open Settings Modal** | `Cmd + ,` | `Ctrl + ,` |
| **Find in Terminal** | `Cmd + F` | `Ctrl + F` |
| **Clear Terminal** | `Cmd + K` | `Ctrl + K` |
| **New Workspace** | `Cmd + Shift + N` | `Ctrl + Shift + N` |
| **Switch Workspace** | `Cmd + Shift + Left/Right` | `Ctrl + Shift + Left/Right` |
| **Navigate Focus** | `Cmd + Arrows` | `Ctrl + Arrows` |
| **Cycle Focus** | `Cmd + Tab` | `Ctrl + Tab` |

---

## 3. Workspaces

Workspaces allow you to group multiple terminal panes into isolated layouts.
- **Create Workspace**: Click `New Workspace` in the header or press `Cmd/Ctrl+Shift+N`.
- **Switch Workspace**: Click the workspace dropdown in the top header or press `Cmd/Ctrl+Shift+Left/Right`.
- **Background Retention**: Active terminal shell processes continue running seamlessly in the background when switching workspaces.

---

## 4. Themes & Customization

Open Settings (`Cmd/Ctrl+,`) to configure:
- **7 Built-in Themes**: `VibeDark` (default), `VibeLight`, `Midnight Blue`, `Solarized Dark`, `Solarized Light`, `Dracula`, and `Nord`.
- **Font Settings**: Choose font family (Fira Code, JetBrains Mono, Menlo) and slider font size (8px to 32px).
- **Scrollback & Cursor**: Configure scrollback lines (100 to 100,000) and cursor styles (`block`, `bar`, `underline`).
